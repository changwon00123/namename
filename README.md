# 판소리대학교 — GitHub Pages 배포용

전통 판소리 전문대학을 가정한 시연용 가상 대학교 홈페이지입니다. 실제 학위·입학 서비스가 아닙니다.

## 새 기능: 음악 감상실
- 메인 화면에서 '소리1 듣기' 클릭
- 화면 하단에 고정된 3곡 음악 플레이어 (재생/정지/이전/다음/볼륨/탐색/반복)
- `#square/audio` 음악 감상실 3곡 카드
- GitHub Pages에서 작동하도록 HTML5 Audio 사용. 자동 재생은 브라우저 정책상 버튼 클릭 후 시작

**중요: 사용자의 MP3 3개는 이 대화에 업로드되지 않아 ZIP에는 음원이 없습니다.** 아래 위치에 실제 파일을 직접 넣어야 재생됩니다.

```
audio/소리1.mp3
audio/소리2.mp3
audio/소리3.mp3
```

기존 사이트 최상위에 이미 MP3가 있다면 `소리1.mp3` 등의 최상위 경로로도 예비 탐색합니다. 음원이 공개 저장소에 업로드되면 누구나 접근할 수 있습니다. 공개 게시 권리 확인 필수.

- 사용자 제공 강문경 총장 프로필의 보정본(`president-kang.webp` + JPG 대체)을 유지했습니다.
- 김판순 단장 소개는 **사용자 제공 공연 무대 사진을 배경/자료 사진으로 적용**했습니다. 사진 속 특정 인물이 김판순 단장이라는 의미가 아니며, 다른 명창 사진을 김판순 단장으로 잘못 게시하지 않았습니다.
- 김판순 단장의 실제 초상권과 재사용 허락이 확인된 독사진을 확보하면 `master-kim.jpg`로 교체하세요.

## 배포
1. 이 폴더 안의 모든 파일과 폴더를 GitHub 저장소의 루트에 업로드
2. Settings → Pages → Deploy from a branch → main / root
3. 이미지와 `audio/` 폴더 구조를 유지
4. 브라우저에서 Ctrl+Shift+R로 새로고침

실제 파일이 업로드되기 전에는 플레이어에 'MP3 파일이 없습니다'라고 나옵니다. 이는 의도된 안내입니다.
